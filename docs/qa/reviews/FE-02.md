## Notes (low / info)
1. The hand-written `RangeValidation` / `LengthValidation` allow neither `min` nor `max`, and don't encode `minimum` limits. The schema's `anyOf` requires one bound and the server validates, so this is harmless. It could be tightened with a union type.
2. Mock fetch serves reads only. `POST /sources`, `POST`/`PUT` pipelines and a few other writes fall through to 404 `not_found` (DELETE returns 204). That is fine for FE-02, but FE-03 and later will need overrides or more routes.
3. The mock `createRun` returns the running fixture with `status` switched to `queued`, so a queued run carries non-zero counters. It is cosmetic, but a fixture that is wrong under §5 could mislead UI tests.
4. The branch is based on `7d2d7b6`. It has no overlap with `main`, so a rebase is optional.
