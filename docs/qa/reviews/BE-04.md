Request-shape 422s (empty/long name, long description, extra field, bad `source_id`, non-object config, malformed JSON, wrong content type) are contract errors.

- **Delete:** 409 while a `queued` or `running` run exists (row kept, delete works once the run is terminal); a delete keeps run history with `pipeline_id` set to NULL; 404 on repeat.

- **Validate:** never persists; `source_id` enables the source-column check, unknown source gives 404; an invalid config is a 200.
- **Safety:** SQL via SQLAlchemy with bound parameters (a name like `x'); DROP TABLE pipelines;--` is stored verbatim); validation goes only through `validate_pipeline_config(..., source_columns=...)`; no `eval`/`exec`; imports the public `app.etl` names only.
